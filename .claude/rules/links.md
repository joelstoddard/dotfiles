# Links

* In replies to the user, you MUST write every link as a full URL (`https://github.com/owner/repo/pull/201`), so it can be opened directly from the terminal or editor.
* You MUST NOT use shorthand references (`#201`, `owner/repo#201`) OR markdown link text that hides the URL.
* You MUST write file references as absolute paths (`/Users/joel/personal/dotfiles/CLAUDE.md:12`), NOT repo-relative ones.
